# iOS Extension tip finger animation

Prototype of the Home Extension tip finger animation, v1: two sets of three upward taps with a 1s pause, plays once (4.3s), 48x42 area, impulse easing, no tap shadow, 6pt travel.

- Desktop view with script controls: open the Pages URL.
- Full-screen phone view: add #mobile to the URL.
- Lottie spec: lottie-spec.md; vector assets: lottie-assets/.
